## ✨ Características y Módulos Implementados

- **Diseño Bento UI & Colores de Referencia:** Lienzo con contenedor redondeado en fondo pastel, bloques azul petróleo profundo (`#054B57`), tarjetas pasteles (lima, melocotón y rosa).
- **Catálogo Interactivo de Gorros Quirúrgicos:** Filtros por categoría (`Todos`, `Molares & Dental`, `Cute Pink`, `Multicolor`), detalle de precio ($180 MXN) y botón de pedido automático a WhatsApp.
- **Agenda de Citas Inteligente:** Formulario con selección de fecha, hora y tratamiento que genera un mensaje formal codificado y listo para enviar al WhatsApp de la clínica, abriendo además una confirmación interactiva.
- **Demostración de Procedimiento Clínico (Modal):** Desglose paso a paso de bioseguridad y odontología de mínima invasión.
- **Optimización para GitHub Pages:** Archivos 100% estáticos (HTML5 semántico, CSS3 moderno, Vanilla JS), compatible con cualquier subdominio o dominio personalizado con archivo `.nojekyll`.
- **SEO Local para Villahermosa, Tabasco:** Etiquetas meta completas, Open Graph, Twitter Cards y marcado estructurado JSON-LD (`schema.org/Dentist`).
- **Botón Flotante de WhatsApp:** Con animación de pulso y acceso rápido en dispositivos móviles.

## 🚀 Despliegue en GitHub Pages

1. **Subir al repositorio de GitHub:**
   ```bash
   git init
   git add .
   git commit -m "feat: Sitio web oficial Dra. Odontóloga y Estilo Molar Villahermosa"
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git
   git push -u origin main
   ```
2. **Activar GitHub Pages:**
   - En tu repositorio de GitHub, dirígete a **Settings** > **Pages**.
   - En **Source**, selecciona **Deploy from a branch**.
   - En **Branch**, selecciona `main` y la carpeta `/ (root)`.
   - Haz clic en **Save**. En menos de 2 minutos tu sitio estará en vivo en:
     `https://TU_USUARIO.github.io/TU_REPOSITORIO/`
